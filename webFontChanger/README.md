# webFontChanger 

Simple web project to change font, background color, and text color using javascript
this project for practicing basic DOM

## Feature
- Change Font
- Change background Color
- Change text color
- Simple Javascript

## Tech Stack
- HTML
- CSS
- Javascript
- Google Font

## How To Use?
- open "index.html" in this folder
- click one of the font button
- the background, font, and text will change

## Structure
├─Index.html 
├─style.css
└─script.js
